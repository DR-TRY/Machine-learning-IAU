# Lab 6 Solution

This folder contains a ready solution for **ARTI308 Lab 6**.

## Included files
- `ARTI308 Lab6 - Solved.ipynb` → solved notebook
- `lab6_task_solution.py` → Python script for the Ecommerce task
- `USA_Housing.csv` → dataset used in the lab example
- `Ecommerce Customers.csv` → dataset used in the lab task
- `requirements.txt` → required packages

## How to run
1. Open the notebook `ARTI308 Lab6 - Solved.ipynb` in Jupyter Notebook or VS Code.
2. Run all cells.
3. Or run the script:
   ```bash
   python lab6_task_solution.py
   ```

## Notes
- The model used is **Linear Regression**.
- The target in the Ecommerce task is **Yearly Amount Spent**.
- Text columns were excluded from modeling because they are not numerical.
